# Safety Notes

This is a personal home lab and proof-of-concept build.

Anyone adapting this project should follow local electrical regulations and use:

- Correct protection devices
- Correct wire sizing
- Safe enclosures
- Proper grounding
- Proper separation between mains wiring and signal wiring
- Suitable terminal blocks and strain relief

Mains voltage can be dangerous.

If you are not qualified to work with mains voltage, ask a qualified electrician to install or review the electrical part of the project.

The Modbus and low-voltage part is simple, but the mains power side must be treated seriously.
